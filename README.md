# Shipborn App voor Home Assistant

Home Assistant-app (add-on) met één paneel en meerdere modules voor je boot:

- **Logboek**: logregels met foto's, PDF, CSV-export en dagmail
- **Onderhoud**: taken met interval in dagen en/of uren (hoofdmotor, generator), stappenplannen met uitleg, afbeeldingen, bediening van HA-entiteiten en verplichte uitvoeringsfoto's, categorieënbeheer, sensoren via MQTT discovery
- **Reizen**: in ontwikkeling
- **Instellingen**: urentellers en logo

## Installeren

1. In Home Assistant: **Instellingen → Apps → store → ⋮ → Repositories**.
2. Voeg toe: `https://github.com/Shipborn/ha-logboek`
3. Installeer **Shipborn App** en start het.

Zie [shipborn_app/DOCS.md](shipborn_app/DOCS.md) voor de instellingen en het gebruik.
